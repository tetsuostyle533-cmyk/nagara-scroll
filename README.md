# ながらスクロール 声操作 1.1.0（音声操作追加・未ビルド）

2026年10月13日。既存1.0.0のソースを修正した開発版です。**インストールできるAPKはこのZIPに含まれません。Androidでのコンパイル、Lint、実機動作は未確認です。**

## 今回の変更

- 「スクロール」で開始、「ストップ」「停止」「止めて」で停止。
- 命令は短い語句の完全一致で判定。一般の文章や否定文では開始しません。
- 停止は途中の音声認識結果でも受け付け、開始は確定結果だけで受け付けます。
- アプリ画面から明示的にON。マイク権限はその時だけ要求します。
- 声操作の状態表示、操作パネルと通知からマイクOFF。
- 声操作は最大15分。画面OFF、パネル終了、ユーザー補助サービス終了時に終了。自動復帰しません。
- マイク終了時はスクロールも停止します。
- 停止後に古いジェスチャー完了通知が次のスクロールを予約する問題を世代番号で防止。
- 音声操作後の再生／停止表示を更新。
- パネルの移動を画面内に制限。ホーム画面はシステムバーを避けて表示。
- アプリ内命令の受信を署名権限で保護（古いAndroidも対象）。

## 使い方（ビルド・実機確認後）

1. 初回のみ、ユーザー補助で「ながらスクロール 声操作」をON。
2. アプリの「声操作をONにする」を押してマイクを許可。
3. ChatGPTやChromeへ切り替える。
4. 「スクロール」と言うと開始。「ストップ」と言うと停止。
5. パネルの−／＋で5段階速度を変更。認識できない時は停止ボタン。
6. マイクOFF、通知の終了ボタン、パネル×で声操作を終了。

ボタン操作はAndroid 7以降。声操作はAndroid 12以降かつ端末内の日本語音声認識に対応する端末で利用可能です。対応していても日本語モデル未導入の場合などは開始できません。認識エラーは表示して終了します。

## 音声の仕組みと制約

Androidの `createOnDeviceSpeechRecognizer()` を使用。クラウド認識への切替は行いません。アプリのインターネット権限、音声録音ファイル、認識文の保存、閲覧内容の読取りはありません。

標準音声認識APIは常時連続認識向けではありません。この版は15分までの試作セッション中に短い認識を繰り返します。認識間に隙間があり命令を取りこぼす可能性があります。騒音、会話中の単語、端末の音声モデルにより誤認識が起こり得ます。手動停止ボタンは常に残します。長時間・確実な待受が必要なら専用のローカル音声エンジンへの変更が次の検討対象です。

停止時は次のスワイプを中止します。既に送信された1本のスワイプは最大約1.15秒で完了します。停止をタップ操作に置換して他アプリのボタンを誤タップする方式は使いません。

公式資料：
- https://developer.android.com/reference/android/speech/SpeechRecognizer
- https://developer.android.com/training/permissions/requesting

## ビルド

JDK 17、Android SDK 35、Build Tools 35.0.0、Gradle Wrapper 8.9／AGP 8.7.3。

Android Studioでフォルダを開き、SDKの場所を設定して同期し、Build APK(s)を実行します。

CLI:
```sh
bash gradlew assembleDebug lintDebug --no-daemon
```

GitHubにこのフォルダをリポジトリのルートとして登録すると、同梱の `.github/workflows/android-build.yml` がビルドとLintを実行し、テスト用APKをActionsのArtifactsに出力します。現時点でGitHubへの登録やこのワークフローの実行は行っていません。

applicationIdは `com.kobatetsu.flowscroll.voice`。旧修正版の署名鍵がないため別アプリとしてインストールします。旧アプリを削除する必要はありません。試用時は旧版のパネルを閉じ、ユーザー補助の旧版をOFFにしてから声操作版をONにしてください。同時に動かすとスワイプが干渉します。

CIはdebug署名鍵をActionsキャッシュに保存し再利用します。キャッシュが消えた場合は別の鍵になります。正式配布前に署名鍵を固定し、安全に保管してください。
