# ながらスクロール 声操作 1.1.1

2026年10月13日。音声操作の接続・再開を改善したテスト版。スマホの実機での認識確認は別途必要です。

## スマホでの更新と使い方

1. 新しい1.1.1のAPKをインストール。同じ声操作版に上書き更新します。
2. 初回のみユーザー補助で「ながらスクロール 声操作」をON。
3. アプリの「日本語音声を準備する」を押す。初回はWi-Fi接続を推奨します。
4. 「声操作をONにする」を押してマイクを許可。「聞いています」を確認します。
5. ChatGPTやChromeで「スクロール」→「ストップ」→「スクロール」を試します。
6. パネルの−／＋で5段階速度を変更。停止ボタン・通知の終了ボタンも使えます。

設定がグレーの場合：設定→アプリ→ながらスクロール 声操作→右上の︙→制限付き設定を許可。
アプリへのマイク権限と端末全体の「マイクのアクセス」の両方が必要です。
旧1.0.0と同時に動かさず、旧版のユーザー補助とパネルをOFFにしてください。

## 1.1.1の変更

- 日本語の端末内音声データを準備するボタンを追加（Android 13以降）。
- 応答が固まった場合や接続エラーでは、認識器を作り直して再接続。
- 無言・聞き取り失敗後も待受を継続。復旧中はスクロールを停止。
- 古い認識器からの通知を無視し、部分結果の停止を同じ発話の最終結果で再開させない。
- ひらがな・半角表記、「スクロールして」「止まって」に対応。否定文や普通の文章では開始しない。
- パネルの「声操作 ON / OFF」から再開用のアプリ画面を開く。
- マイク・日本語データなど、原因に応じた状態表示。
- 画面OFFの受信をアプリ内命令と分離し、ボタン操作中も画面OFFで停止。

## 音声とプライバシー

ボタンはAndroid 7以降。声はAndroid 12以降と端末内の日本語音声認識が必要です。
音声操作は最大15分。画面OFF、マイクOFF、パネル終了、ユーザー補助終了で停止。
終了後やプロセス終了後に勝手にマイクを再開しません。

Androidの端末内音声認識のみ使用します。クラウド音声認識には切り替えません。
アプリに通信権限はありません。日本語モデルのダウンロードは端末の音声認識サービスが実施します。
音声・認識文・閲覧内容をファイルに保存せず、画面の文字も読み取りません。

標準音声認識APIは常時連続認識向けではありません。短い認識を繰り返すため切替中の隙間は残ります。
騒音や音声モデルによって聞き取れない場合があります。認識が失われたときは自動スクロールを止めます。
停止時は次のスワイプを中止。送信済みの1本は最大約1.15秒で完了します。

## ビルドと検証

JDK 17、Android SDK 35、Build Tools 35.0.0、Gradle Wrapper 8.9／AGP 8.7.3。

```sh
bash gradlew assembleDebug lintDebug --no-daemon
```

main更新時のGitHub Actionsで30件の命令判定・APKビルド・Lintを実行。
成功時のみReleasesに `NagaraScroll-voice-v1.1.1.apk` を公開します。

applicationIdは `com.kobatetsu.flowscroll.voice`。versionCodeは3。
CIの署名鍵をActionsキャッシュで再利用。キャッシュが失われると上書き更新できなくなる場合があります。
署名鍵はGitに登録しません。

実機での確認対象：日本語データ未準備、マイク許可・拒否・取消、端末マイクOFF、
無言の待受、開始→停止→再開、他アプリへの切替、認識サービスの切断、
画面OFF・パネル終了・15分終了、Android 12／14／17。
