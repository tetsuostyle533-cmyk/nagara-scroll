# ながらスクロール 声操作 1.1.3

2026年10月13日。1.1.2の「速度1が速い」「動いて止まる」という実機報告への修正版。
Android 8以降では、同じタッチをつないだ連続ドラッグへ変更しました。実際の滑らかさは端末・対象アプリで確認が必要です。

## スマホでの更新

1. 新しい1.1.3のAPKを開いて上書き更新。
2. アプリで操作パネルを表示し、速度1で試します。
3. 声操作はアプリからONにし「スクロール」「ストップ」で開始・停止。
4. 初回の音声データが未準備なら「日本語音声を準備する」を押します。

初回のユーザー補助がグレー：設定→アプリ→ながらスクロール 声操作→右上の︙→制限付き設定を許可。
旧1.0.0のユーザー補助とパネルはOFFにしてください。

## 1.1.3の変更

- Android 8以降はStrokeDescription.continueStrokeで同じポインターを継続。
- 通常の移動区間は120ms。区間ごとに指を離さず、意図的な待ち時間を挟みません。
- 速度1〜5は8／16／28／44／68dp毎秒。1.1.2の速度1（計画上約42dp毎秒）から大幅に低速化。
- ドラッグ開始時だけタッチ移動のしきい値を80msで越え、その後は一定速度で移動。
- 画面端では同じポインターを60msで離し、下側から新しいドラッグを開始。端の切替と開始時の短い動きは残ります。
- 停止時は進行中の区間を完了し、同じポインターを離す。別のタップを送る方式は使用しません。
- 速度変更は次の区間に反映。タッチを切らずに速さを変更。
- キャンセル・拒否されたジェスチャーは継続状態を捨て、再接続。
- Android 7は通常のスワイプへフォールバックし、連続タッチと同じ滑らかさにはなりません。

操作パネルの回避、速度の上下限表示、音声接続復旧、日本語音声準備は維持します。

## プライバシーと音声

画面の文字を読み取りません。音声・認識文・閲覧内容はファイルに保存しません。
クラウド音声認識へ切り替えず、端末内の日本語認識を使用します。
アプリに通信権限はありません。音声モデルの準備は端末の音声認識サービスが行います。
声はAndroid 12以降。マイク権限と端末のマイクのアクセスの両方が必要です。
最大15分。画面OFF・パネル終了・マイクOFF・ユーザー補助終了で停止し、勝手に再開しません。

## ビルドと検証

JDK 17、Android SDK 35、Build Tools 35.0.0、Gradle 8.9／AGP 8.7.3。
mainへの更新で命令判定30件、5段階×3画面密度の連続移動テスト、APKビルド、Lintを実行。
移動テストは経路のつながり、一定速度、画面端での静止したままの指離し、途中の速度変更を検証。
実機の描画・滑らかさ・タッチ操作・音声操作は別途確認が必要です。

```sh
bash gradlew assembleDebug lintDebug --no-daemon
```

成功時のみReleasesにNagaraScroll-voice-v1.1.3.apkを公開。
applicationIdはcom.kobatetsu.flowscroll.voice、versionCodeは5。
CI署名鍵をActionsキャッシュで再利用します。キャッシュが失われると上書き更新できない場合があります。
